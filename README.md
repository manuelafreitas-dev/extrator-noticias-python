# 📌 Extrator Inteligente de Notícias (Web Scraper)

Uma ferramenta automatizada com interface gráfica desenvolvida em **Python** que realiza raspagem de dados (Web Scraping) em tempo real no portal de Economia do G1.

## 🚀 Funcionalidades

- **Raspagem em Tempo Real:** Conecta ao site do G1 e extrai as 10 principais manchetes do momento com apenas um clique.
- **Coleta de Links:** Além do título da notícia, o programa captura o link direto para que o usuário possa ler a matéria completa.
- **Interface Intuitiva:** Área de texto rolável integrada com `customtkinter`, facilitando a leitura dos dados coletados de forma organizada.
- **Tratamento de Erros:** Sistema preparado para avisar o usuário caso haja instabilidade na conexão com a internet.

## 🛠️ Tecnologias Utilizadas

- **Python** (Linguagem principal)
- **BeautifulSoup4** (Extração e raspagem de dados HTML)
- **Requests** (Requisições HTTP para acessar o site)
- **CustomTkinter** (Interface Gráfica)
