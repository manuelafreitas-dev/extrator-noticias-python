# 📁 Organizador Inteligente de Arquivos

Uma ferramenta de automação com interface gráfica moderna desenvolvida em **Python** para resolver um problema real de produtividade: a organização de pastas de arquivos bagunçadas (como a pasta de Downloads).

## 🚀 Funcionalidades

- **Interface Visual Moderna:** Desenvolvida com a biblioteca `customtkinter`, oferecendo um visual limpo e adaptável ao tema do sistema.
- **Organização em um Clique:** O usuário escolhe a pasta desejada e o programa cria subpastas automaticamente, movendo cada arquivo para o seu devido lugar.
- **Filtro por Extensões:** 
  - **Documentos:** .pdf, .docx, .xlsx, .txt, etc.
  - **Imagens:** .jpg, .jpeg, .png, .gif, etc.
  - **Instaladores e Zips:** .exe, .msi, .zip, .rar, etc.
  - **Vídeos e Áudio:** .mp4, .mkv, .mp3, etc.

## 🛠️ Tecnologias Utilizadas

- **Python** (Linguagem principal)
- **CustomTkinter** (Interface Gráfica)
- **OS & Shutil** (Manipulação de arquivos do sistema)
